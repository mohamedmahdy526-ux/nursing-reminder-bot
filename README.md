# 🏥 Nursing Reminder & Discussion Bot

بوت تليجرام تعليمي وسريري لممارسي وطلاب التمريض، يقدم **معلومات تمريضية دورية وأسئلة MCQ تفاعلية** باللهجة المصرية العامية، مع إمكانية **النقاش والدردشة المباشرة** مع البوت حول أي معلومة أو حالة سريرية.

---

## ✨ المميزات الرئيسية

* 💬 **النقاش والدردشة التفاعلية**: تقدر ترد على أي معلومة أو تسأل البوت مباشرة في الشات (مثال: *"طب لو المريض عنده هبوط في الضغط أعمل إيه؟"*) وهيرد عليك بأسلوب ممرض سينيور ومحاضر خبير.
* 🩺 **8 أقسام تمريضية تخصصية**:
  1. حديثي الولادة (NICU)
  2. العناية المركزة (ICU)
  3. تمريض الأطفال (Pediatric)
  4. الأدوية للتمريض (Pharmacology)
  5. المصطلحات الطبية (Terminology)
  6. سلامة المرضى وتواصل ISBAR
  7. رسم القلب والقلبية (ECG & Cardiac)
  8. الطوارئ والحوادث (Emergency & Trauma)
* 📊 **كويزات تفاعلية حقيقية (Telegram Native Quiz Poll)**: تضغط على الاختيار ويظهر لك صح أو غلط مع الشرح فوراً.
* ⏰ **تذكير دوري بالساعة**: يرسل معلومة كل ساعة (08:00 إلى 22:00 بتوقيت القاهرة).
* 🔄 **وضعيتين للتشغيل**:
  1. `interactive_bot.py`: وضع السيرفر 24/7 (GSM Host / VPS / محلي) مع دعم الدردشة والنقاش اللحظي.
  2. `bot.py`: وضع الـ Serverless عبر GitHub Actions بدون أي سيرفر.

---

## 📋 هيكل المعلومة المرسلة

كل رسالة بتيجي مقسمة بأسلوب تعليمي منظم:
1. 🏥 **معلومة** — شرح مباشر وسريري بالمصري العامي.
2. ❓ **ليه مهمة؟** — الأهمية السريرية وعواقب إهمالها.
3. 🔗 **Clinical Connection** — ربط بحالة عملية أو سيناريو واقعي في المستشفى.
4. 🧠 **طريقة حفظ** — Mnemonic بالأحرف الأولى لتسهيل التذكر.
5. 📚 **المصدر** — مرجع معتمد (WHO / CDC / NANDA / Smeltzer / Kozier).

## 🧰 Tech Stack

- **Python 3.11+**
- **OpenRouter API** (موديلات مجانية: Minimax, Gemma, Nemotron)
- **Telegram Bot API** (HTML formatting + Native Quiz Polls)
- **GitHub Actions** (للتشغيل المجدول السيرفرلس) أو **GSM Host / VPS** (للتشغيل التفاعلي)

## 🚀 التشغيل

### 1. تنصيب المكتبات
```bash
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية (Environment Variables)
```bash
export TELEGRAM_BOT_TOKEN="توكن_البوت"
export TELEGRAM_CHAT_ID="معرف_الشات"
export OPENROUTER_API_KEY="مفتاح_أوبن_روتر"
export OPENROUTER_MODEL="minimax/minimax-m3:free"
```

### 3. التشغيل التفاعلي 24/7 (يدعم النقاش المباشر والردود)
```bash
python interactive_bot.py
```

### 4. التشغيل المجدول لمرة واحدة (Job Mode)
```bash
python bot.py
```

## 💬 الأوامر في البوت التفاعلي

| الأمر | الوظيفة |
|---|---|
| `/ثقف` أو `/start` | عرض الأقسام التمريضية الـ 8 واختيار التخصص |
| `/اختار [رقم]` | اختيار قسم محدد (مثال: `/اختار 2` للعناية المركزة) |
| `/معلومة` | جلب معلومة سريرية مشروحة بالمصري من القسم المختار |
| `/mcq` | سؤال كويز تفاعلي تضغط على الإجابة وتعرف نتيجتك |
| `/جديد` أو `/reset` | تصفير الذاكرة وسياق النقاش لبدء موضوع جديد |
| `/قسم` | إظهار القسم المختار حالياً وآخر موضوع |
| `/status` | فحص حالة واتصال البوت |
| **أي رسالة عادية** | **نقاش واستفسار فوري مع البوت حول المعلومة السابقة أو أي سؤال سريري!** |
