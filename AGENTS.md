# Project Rules & Workflow

## Git & Deployment Protocol
- **Always Commit and Push**: Whenever code modifications or improvements are made, immediately commit and push them to GitHub (`origin/main`) so that the remote hosting server (GSM Host / VPS) can receive the latest updates.
- **Security Check**: Always verify `.env` is ignored and never stage sensitive credentials.
- **Commit Quality**: Use concise, clear commit messages summarizing what was fixed or added.
